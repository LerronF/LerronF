## 👋 Sobre mim

Sou **desenvolvedor fullstack** em Manaus, com base sólida em **C# / .NET** e **SQL Server** e atuação crescente em
**Node.js, PostgreSQL e PWAs**. Construo sistemas **desktop, web e mobile** — de ERPs e integrações com filas
(**RabbitMQ**) a apps que funcionam **sem internet** no celular de quem está na estrada. Tenho experiência como
**líder de equipe** e gosto de transformar problemas do dia a dia de pessoas reais em software simples de usar.

Hoje toco os produtos da **DevTime Sistemas**, com um fluxo profissional de ponta a ponta: **testes automatizados,
CI no GitHub Actions, ambientes de staging e produção** e **IA** tanto dentro dos produtos quanto no meu jeito de
desenvolver.

## ⚙️ Como eu trabalho

- ✅ **Nada vai para o cliente sem passar nos testes** — testes automatizados + GitHub Actions, e o deploy só sai com tudo verde
- 🧪 **Staging antes da produção** — cada mudança é validada num ambiente de testes antes de chegar ao usuário
- 📱 **Offline-first** — apps que guardam os dados no aparelho e sincronizam sozinhos quando o sinal volta
- 🔄 **Versão visível e atualização automática** — o usuário sempre está na versão mais nova, sem reinstalar
- 🤖 **IA no produto e no processo** — uso a API do Claude dentro dos apps e o Claude Code no meu dia a dia de desenvolvimento
- 📘 **Documentação junto com o código** — manual do usuário com telas reais e changelog a cada entrega
