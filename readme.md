## 🏭 Experiência técnica

**MES de chão de fábrica (indústria)** — apontamento de produção, OEE, alarmes, integração com ERP e painel mobile para
gestores, numa plataforma que substitui um sistema legado mantendo o mesmo banco e as mesmas regras de negócio.

- **Sincronização offline-first entre bancos** — cada linha de produção roda com SQL Server Express local; as
  alterações são capturadas por **Change Tracking**, publicadas no **RabbitMQ** (exchange direct, fila por origem) com
  **transactional outbox** e **chave de idempotência SHA-256**, consumidas com **retry e dead-letter queue** e
  mescladas no banco central, nos dois sentidos
- **Serviços Windows resilientes** — supervisor com **heartbeat**, reinício automático e **circuit breaker**; jobs
  agendados com **Quartz**; logs com Serilog e log4net
- **Monorepo .NET multi-target** — solução e build únicos para desktop **WinForms + DevExpress**, **ASP.NET Core** (REST,
  OAuth, Swagger, Razor), serviços, integração e instaladores **Inno Setup**, convivendo .NET Framework 4.5/4.8 e
  .NET 6/8/9
- **Modernização de legado** — porte de regras de **EF6 / ASP.NET Web API / WCF / AngularJS** para APIs novas, acesso a
  dados com **Dapper e EF Core**, todo o DDL versionado num projeto único de migrações e build zerado de warnings
- **Arquitetura protegida por testes** — testes de arquitetura (solução única, fronteira entre módulos, nada de
  credencial no código), **NUnit, xUnit, Moq, coverlet, Selenium** e testes com **LocalDB**
- **CI/CD** — pipeline **Jenkins** com build de imagem **Docker**, HTTPS com certificado e health check; GitLab com
  merge request e branches de homologação e produção
- **SSO Gateway com Ocelot + .NET 8** — autenticação centralizada e roteamento de microsserviços via API Gateway

**Projetos próprios em produção** — .NET 10 + **Blazor Interactive Server**, **PostgreSQL/EF Core** com pgvector, fila
de jobs em tabela com `FOR UPDATE SKIP LOCKED`, **Testcontainers**, cifra **AES-256** de dados pessoais, CSP, rate
limiting e bloqueio de login (LGPD), **Pix com API do banco via mTLS e webhook**, storage S3 (Cloudflare R2), geração de
PDF com QuestPDF, **API do Claude** com saída validada por JSON, app **.NET MAUI** (Android); em Node.js, **Express 5 +
PWA offline-first** com Service Worker, Web Push e WhatsApp Cloud API; deploy em **Docker + Railway** com staging.

## 💼 Por que me contratar como dev ou tech lead?

- **19 anos entregando software que roda em operação real** — chão de fábrica, frota na estrada, ação social sem
  internet, pagamentos por Pix. Sei o que acontece quando o sistema para, e projeto para ele não parar
- **Já liderei equipe** — divisão do trabalho, revisão de código, padrões do time e a palavra final
  nas mudanças críticas de arquitetura
- **Resolvo problema difícil de sistema distribuído** — consistência entre bancos sem perder nem duplicar dado
  (outbox, idempotência, dead-letter, reprocessamento), serviço que se recupera sozinho, integração com ERP
- **Modernizo legado sem reescrever do zero** — tiro regras de negócio de código antigo, levo para APIs novas e
  mantenho o mesmo banco em produção durante a migração
- **Transformo regra em teste** — o que é importante para o time vira teste de arquitetura ou de integração e trava o
  build, não fica só num documento
- **Entrego de ponta a ponta sozinho, se precisar** — modelagem de banco, API, desktop, web, PWA, app Android, CI/CD,
  Docker, deploy e manual do usuário
- **Segurança e LGPD desde o desenho** — bacharel em Direito: cifra de dados pessoais, bloqueio de login, CSP,
  registro de aceite e retenção de dados entram no plano, não no fim
- **IA aplicada com critério** — uso o Claude Code no desenvolvimento e a API do Claude em produto, com saída validada,
  fonte citada e revisão humana
